# موقع المحل — شباتي وملفوف

## التصحيحات اللي درتها
- كان `vite.config.js` مرفوع باسم غلط (`vite_config.js`) — تصحح.
- المشروع كان ناقص كل ملفات React (`src/*`) — زدتها كاملة.
- ثبّتت أرقام واضحة للمكتبات بدل `"latest"` باش المشروع يبقى ثابت مستقبلاً.

## كيفاش تخدم بيه محلياً
```
npm install
npm run dev
```
يفتح على `http://localhost:5173`

## كيفاش تبني نسخة الإنتاج
```
npm run build
```
يطلعلك مجلد `dist/` ترفعه لأي استضافة (Netlify, Vercel, Hostinger...)

## وين تبدل المعلومات ديالك
كل شي كاين في ملف وحد: `src/config.js`
- `name` : اسم المحل
- `tagline` : الجملة تحت الاسم
- `whatsappNumber` : رقم الواتساب بلا `+` وبلا صفر البداية (مثال جزائري: `213555xxxxxx`)
- `address` و `hours` : العنوان والتوقيت
- `menuGroups` : أطباق الشباتي والملفوف، كل واحد بالاسم والوصف والثمن

كي تبدّل رقم الواتساب أو الأطباق، الموقع كامل يتبدل وحدو، ماكاش داعي تروح للكود.

## آخر تحديث
- النصوص كاملة تصححت للجزائرية المحترفة (بلا كلمات مصرية كيما "دلوقتي").
- تصميم المنيو تبدل لكروت "قصة" (Story Cards) مستوحاة من فيديو ترويجي: كل طبق بخلفية دقرادي لونها مختلف، صورة الطبق فيها أنيميشن طفو (float) مستمر خفيف، بادج بيضاء للسعر، وزر طلب أحمر — بلا أي مكتبة أنيميشن، كلشي CSS خفيف.
- فالموبايل: الكروت فشريط أفقي (سناب سكرول)؛ فالديسكتوب: شبكة.

## الصور
حطيت صور مؤقتة من Unsplash (مجانية للاستخدام التجاري، بلا حقوق) حتى تجيب صور محلك الحقيقية. راهي كلها متجمعة فملف `src/config.js`:
- `heroImage` : صورة خلفية القسم الأول
- `image` جوه كل طبق فـ `menuGroups`

بش تبدلها بصورك:
1. حط الصور ديالك فمجلد `public/images/` (أنشئه إيلا ما كانش)
2. بدّل الرابط بـ `/images/اسم-الصورة.jpg`

**ملاحظة:** الصور الحالية مأخوذة من Unsplash عبر رابط مباشر (hotlink) — تخدم مليح للتجربة، بصح يفضل تبدلها بصورك الحقيقية للمحل قبل ما تنشر الموقع بصفة نهائية، حتى تكون الصور مطابقة لأكلك الحقيقي.

## الأنيميشن
خفيف بزاف قصدياً (طلبك): حركة وحدة كي يفتح الموقع (العنوان، الجملة، الزر يطلعو بالتدريج)، وتفاعلات بسيطة كي تحوّس بالماوس على الكروت والأزرار. ماكاين حتى مكتبة أنيميشن خارجية — كلش CSS خفيف باش الموقع يطلق بسرعة.
